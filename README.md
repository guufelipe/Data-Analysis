# Data-Analysis
  Análise exploratória de dados educacionais, com foco na avaliação de desempenho de alunos com base em notas, frequência e sexo. Projeto desenvolvido em Python com uso da biblioteca Pandas.

# Estrutura do Repositório:

  ├── datasets/
  │   └── base_padronizada.csv   # Arquivo CSV com os dados limpos e padronizados
  │
  ├── analise_dados.py           # Script com todas as etapas da análise utilizando Pandas
  ├── analise_final.pdf          # Relatório final em PDF com gráficos e insights
  └── resumo_etapas_analise.pdf  # Documento explicando o passo a passo do processo analítico

# Etapas da Análise

1. **Contagem e Percentual de Aprovados/Reprovados**
   - Cálculo da média final dos alunos com base nas notas e frequência.
   - Classificação como "Aprovado" ou "Reprovado" segundo a média.

2. **Análise por Gênero**
   - Distribuição absoluta e relativa de aprovação por sexo.
   - Comparação entre participação e desempenho entre alunos masculinos e femininos.

3. **Ranking de Desempenho**
   - Listagem dos 5 alunos com as maiores médias finais.

4. **Ranking de Assiduidade**
   - Listagem dos 5 alunos com maior frequência registrada.

#  Tecnologias Utilizadas

  - **Python**
  - **Pandas**

#  Objetivo

Demonstrar o uso de ferramentas de análise de dados para extrair informações úteis de uma base educacional, permitindo interpretações quantitativas sobre o desempenho e frequência dos alunos.
